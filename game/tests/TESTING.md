# ผลการตรวจสอบ — 22 พฤศจิกายน 2026

## Automated tests

รัน `node --test tests/core.test.cjs` จากโฟลเดอร์ `game/` ผ่านครบ 13 ชุด

- ทีมตั้งต้นของ A และ B ถูกต้อง เรียงตาม id 1-2-3 และแต้มรวมพอดี 100
- `index.html` โหลดเฉพาะไฟล์ในเครื่องที่มีอยู่จริง ไม่มีช่องเลือกมอนสเตอร์ และรูปของนักเรียนหาเจอทุกรูป
- ลำดับธาตุ: แต่ละธาตุชนะ 1 ธาตุและแพ้ 1 ธาตุ คู่ที่ไม่ติดกันได้ ×1 ชื่อธาตุภาษาไทยใช้ได้
- บัพทีมได้ 1 / 2 / 3 ตามจำนวนธาตุที่ไม่ซ้ำ ธาตุในทีมเดียวกันไม่ข่มกัน
- ทีมที่ขาด id บางลำดับ, id ลงท้ายซ้ำ หรือธาตุสะกดผิด จะถูกปฏิเสธ
- จำลอง 40 seed: ลงสนามตามลำดับ 1→2→3 เท่านั้น, ตัวที่ชนะยังมี HP เท่าเดิมตอนสลับตัว, HP ไม่หลุดขอบเขต และฝ่ายแพ้หมดแรงครบ 3 ตัว
- ตีธาตุที่เราแพ้แล้วบัพไม่ทำงาน (ไฟตีน้ำแล้วไม่เผาซ้ำ แต่ตีธาตุปกติยังเผาซ้ำ)
- บัพน้ำช่วยรอดตายได้ไม่เกิน 1 ครั้งต่อตัว
- ดีบัพจากสายฟ้าและน้ำแข็งไม่เกินเพดาน
- ระบบลดค่าเกินเพดานและเกินงบ 100 โดยไม่แก้ข้อมูลต้นฉบับ
- critStrike ทำให้คริได้แม้ critical = 0, hardCrit ทำให้ดาเมจคริแรงขึ้น และทุกเหตุการณ์บอกสกิลที่ใช้ การหลบ และคริติคอลแยกฝั่ง
- path รูปต้องอยู่ในโฟลเดอร์ของนักเรียนคนนั้นเท่านั้น
- ทุกเหตุการณ์มีตัวเลขดาเมจ/ฟื้น HP แยกฝั่งให้หลอดเลือดใช้ และมีเครื่องหมายบอกว่าตัวไหนหมดแรง ทุกครั้งที่มีตัวหมดแรง (ยกเว้นครั้งสุดท้าย) จะตามด้วยการสลับตัว

## ตรวจในเบราว์เซอร์จริง (Chrome แบบ headless)

- ก่อนเริ่ม: มอนสเตอร์เป็นเงา ชื่อแสดงเป็น ??? และจุดนับตัวครบ 3 จุด
- ระหว่างสู้: ชื่อแสดงป้ายธาตุสีนำหน้า เช่น [น้ำแข็ง] จอห์นซีน่า ป้ายด้านบนบอกว่าเป็นตัวที่เท่าไหร่ และหลอดเลือดมีแถบแดง/เขียวพร้อมตัวเลขลอยขึ้น
- ดูผลทันทีข้ามไปจนจบเฉพาะคู่ปัจจุบัน แล้วขึ้นปุ่ม สู้ต่อ เมื่อจบทั้งเกมขึ้นปุ่ม ต่อสู้อีกรอบ
- พอมีตัวหมดแรง: เกมหยุดรอ กดสู้ต่อแล้วตัวถัดไปลงสนาม วงกลมลำดับเปลี่ยนเป็น ✕ และหลังจบเกมประกาศทีมผู้ชนะ
- Console ไม่มี error
