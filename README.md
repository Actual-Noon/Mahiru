# Monster Forge 🐉

เกมสร้างมอนสเตอร์แล้วจับมาสู้กัน สำหรับฝึกใช้ Git และ GitHub

## เริ่มเล่นใน 3 ขั้นตอน

1. **เลือกฝั่งของตัวเอง:** เป็นคน A หรือคน B
2. **แก้มอนสเตอร์ของตัวเอง:** เปิดไฟล์ในโฟลเดอร์ของตัวเองเท่านั้น

   | คน | ไฟล์ที่ต้องแก้ (มอนสเตอร์ทั้ง 3 ตัว) | ที่วางรูป |
   | --- | --- | --- |
   | A | `student-a/monsters.js` | `student-a/images/` |
   | B | `student-b/monsters.js` | `student-b/images/` |

3. **เปิดสนามต่อสู้:** ดับเบิลคลิก **`game/index.html`** ทุกครั้งที่แก้ไฟล์ ให้กดบันทึกแล้วรีเฟรชหน้าเว็บ (F5)

## ในไฟล์ `monsters.js` แก้อะไรได้บ้าง

แต่ละไฟล์มีมอนสเตอร์ 3 ตัว ตัว `1` ลงสนามก่อน ตามด้วย `2` และ `3` ทีมที่หมดแรงครบ 3 ตัวก่อนแพ้

- `name`, `description`: ชื่อและคำอธิบาย
- `image`: รูป ให้วางไฟล์ไว้ใน `images/` ของตัวเอง แล้วเขียนเป็น `"images/ชื่อรูป.png"`
- `element`: ธาตุ เลือกจาก `wind` ลม / `rock` หิน / `plant` พืช / `fire` ไฟ / `water` น้ำ / `ice` น้ำแข็ง / `lightning` สายฟ้า
- `skill`: สกิลพิเศษ เลือกจาก `strike` / `critStrike` / `poison` / `heal` / `shield`
- `trait`: ความสามารถติดตัว เลือกจาก `none` / `thorns` / `regeneration` / `berserk` / `hardCrit`
- `stats`: แต้มสเตตัส รวมกันได้ไม่เกิน 100

ทุกบรรทัดในไฟล์มีคอมเมนต์อธิบายไว้แล้ว ห้ามเปลี่ยน `id` และระวังอย่าลบเครื่องหมาย `" , { } [ ]`

## โครงสร้างโฟลเดอร์

```
student-a/   ← ของคน A
student-b/   ← ของคน B
game/        ← โค้ดเกมทั้งหมด (ไม่ต้องแก้) + index.html สำหรับเปิดเกม
```
